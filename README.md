# AquaFresh Log Monitoring

A beginner-friendly Python log monitoring project for AquaFresh Water Delivery.

The project reads sample authentication and web access logs, extracts useful information, and creates a structured CSV file.

## Project Files

- `auth.log` - Sample authentication log entries.
- `access.log` - Sample web access log entries.
- `parser.py` - Python script that parses both log files.
- `parsed_logs.csv` - Structured CSV output generated by the parser.
- `tests/test_parser.py` - Pytest unit test for the log parser.
